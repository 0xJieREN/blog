# butterfly

一支 24.3 秒的方形短片：Claude.mp4 里出现过的 14 种蝴蝶和蛾，每一只都被重新做成一张版画，按 Kevin T. Ngo "self-portraits" 的结构排列。中心的主体位置和面积不变，翅膀里的纹样、背景、工艺每一刀都换。音乐的写法学的是原视频的配乐：速度一直稳在 160 BPM，越来越快的是音符本身（整小节 → 八分 → 十六分）、一层层加厚的声部和不断的渐强。剪辑跟着它从 1.5 秒一刀加到 0.19 秒一刀，最后在一个强拍上停在红带蛱蝶上。

画面全部由 JavaScript 在 canvas 上画出来，没有贴任何原视频的像素；音乐是为这条剪辑表专门写、用 numpy 逐个音符合成的原创曲。

## 顺序：色相环，转三圈

14 只蝴蝶排成色相环上的一圈，每一只都把自己的一种颜色交给下一只：

黄窗斑蛾（黄、黑）→ 狗脸粉蝶（黄）→ 达摩凤蝶（奶黄、黑）→ 小型奶斑凤蝶（奶色、橄榄）→ 夹竹桃天蛾（橄榄绿）→ 绿带凤蝶（绿、青）→ 透翅蛾（透明、绿）→ 灰蝶（蓝）→ 暗色日行蛾（蓝黑、橙、红）→ 淡色眼蝶（奶色、泛红）→ 红橄榄天蛾（绯红）→ 红带袖蝶（黑、猩红）→ 斑蛾（红、黑）→ 红带蛱蝶（红、石板灰），它的红再接回黄窗斑蛾的红色腹部。

这个色相环跟着音乐转三圈，一圈比一圈快：第一圈每只先占一小节、然后半小节，第二圈每只 3 个或 2 个八分音符，第三圈每只 1 个八分音符。

- **第一张：黄窗斑蛾。** Claude.mp4 第一帧画面正中间就是它（图鉴 fig. 9），原片最后一帧也是放大的它。
- **最后一张：红带蛱蝶。** 原片高潮时冲向镜头的就是这只。成片最后停在它身上 1.75 秒，右上和左下各有一个红色套印十字线，像一张版画印完的落款。
- 第一圈（慢）里每只都用本色和它的招牌工艺出现；后两圈有 8 张反相版，让浅色和深色主体交替出现，连续同明度最多三张。

## 设计

- **一个主体，两种处理。** 每张图先画平面的背景和标本，再用同一种工艺（`js/crafts.js`）分别处理背景和主体：主体更细密、方向从翅根向外放射（像翅脉），背景更粗、换方向。没有描边，主体的边缘只是处理方式变化的地方。
- **背景来自这只蝴蝶自己的翅膀**（`js/grounds.js`）：黄窗斑蛾背景是它的三条黄窗斑和腹部色环，斑蛾是黑圈红点，绿带凤蝶是一排绿方块，灰蝶是鳞片纹，达摩凤蝶是奶黄逗点和格子，夹竹桃天蛾是波浪带，红带蛱蝶是斜红条和折线，透翅蛾是翅脉格子和放射线。明度和主体相反，每张都测过主体/背景亮度差（71–171，Kevin 的是 78–116）。
- **反相版**：深色翅变成纸色，浅色斑变成墨色，鲜艳的点缀色保留；背景同色相、明度反过来。
- **十种工艺**：丝网（错版+干刷痕）、麻胶版（刻刀痕）、马赛克、十字绣、半调网点（riso）、铜版线刻、水粉点、缎面绣、翅鳞、点描。每个物种三次出场用三种不同工艺和三套不同背景，相邻两张从不重复工艺。
- **静止。** 每张图只画一次并缓存，同一张图内的帧完全相同（图内像素变化 0.00%），所有变化都在切点上。

## 音乐

`tools/music.py` 为这条剪辑表写出并合成整首曲子。乐器有马林巴（主奏）、拨奏弦乐（低音提琴和小提琴）、木块，弦乐长音和弓拉低音负责和声与低音，再加一点点羽管键琴。没有鼓，没有 drop。

**原曲是怎么"加速"的（从 Claude.mp4 的频谱分析出来）**：从第一个大强拍开始，它的速度基本稳在 160 BPM 左右，音和音之间 0.09 秒，也就是十六分音符。越来越快的感觉来自这几件事：音越来越碎，一层层往上加，大约 12 dB 的渐强，高频越来越满，一个低音长音鼓起来顶进强拍，到顶突然全部切断，再接一下重击。

这一版就照这个写法来：**速度固定 160 BPM，变快的是蝴蝶和音符。**

| 小节 | 图 | 每只 | 时长 | 音乐 |
| --- | --- | --- | --- | --- |
| 1–4 | 1–4 | 一小节 | 1.50 s | 每个强拍一组拨出来的和弦（羽管键琴加拨弦），几个马林巴音，中间留空，高处有轻轻的"咔哒"（原曲开头那种）；弦乐长音铺底，一个低 D 长音一路鼓起来 |
| 5–9 | 5–14 | 半小节 | 0.75 s | 起飞：马林巴八分音符循环音型；低音提琴拨奏落在每个切点；小提琴拨弦在反拍；第 7 小节起第二支马林巴晚十六分音符错位跟奏 |
| 10–14 | 15–28 | 3+3+2，然后 2 个八分音符 | 0.56 / 0.38 s | 十六分音符铺满（就是原曲那种 0.09 秒的脉冲）；每个切点都有木块，加十六分音符的轻敲；低音提琴改成八分音符行走；羽管键琴在切点点一下 |
| 14–15 | 29–41 | 1 个八分音符 | 0.19 s | 每个八分音符都是一刀，木块每个八分音符都敲；马林巴同音十六分音符反复，糊成一片；最响 |
| 呼吸 | 41 | | | 全部切断，只剩一个干木块 |
| 16 | 42 | 停留 | 1.75 s | D 大和弦：低音拨奏、弦乐和弓拉低音回来、马林巴和弦加一段渐弱的滚奏、羽管键琴快速琶音 |

**和声与低音**：弦乐长音（四个声部）每小节换一个和弦，D 多利亚调式：Dm9、B♭maj7、C6/9，然后进入 Dm9、B♭maj7、Gm9、C6/9、A7sus–A7，第二圈再走一遍，在第三圈停在 A7 上制造张力，最后解决到 D 大三和弦（皮卡迪三度，收得明亮）。弓拉低音托着每个和弦的根音，低音提琴拨奏在上面打节奏。

**整体动态**：一条"指挥"曲线控制全曲音量。开头最轻，第 5 小节起飞时跳一档，然后一路渐强，第三圈到顶，从第一小节到顶点大约 14 dB。

切点取最近的整帧（30 fps），离它对应的音符最多 17 ms。

**关于现成音乐：** 先找过可合法使用、节拍真加速的现成曲目。Pixabay Music 在这个环境里返回 403，Freesound 的 CC0 搜索也没有合适的器乐。所以写了原创曲，没有第三方授权问题，切点也能精确地踩在音符上。

## 重新生成

```bash
python3 tools/music.py
node ../.claude/skills/line-drawn-music-film/scripts/render.cjs --project . --audio audio/music.mp3 --fps 30 --out out/butterfly.mp4
python3 tools/sync_check.py out/butterfly.mp4
node tools/check.cjs            # 所有图拼成一面墙，并逐张检查对比度
```

`tools/music.py` 写出 `audio/music.mp3` 和 `js/beats.js`（切点）。在浏览器里打开 `index.html` 可以直接带声音播放（空格暂停，方向键跳转）。

成片：1080×1080，30 fps，H.264 High / yuv420p，AAC 44.1 kHz，24.27 秒，42 张图，约 19 MB。
