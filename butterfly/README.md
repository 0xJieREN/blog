# butterfly

一支 24 秒的方形短片：Claude.mp4 里出现过的 14 种蝴蝶和蛾，每一只都被重新做成一张版画，按 Kevin T. Ngo "self-portraits" 的结构排列。中心的主体位置和面积不变，翅膀里的纹样、背景、工艺每一刀都换。音乐真的在加速（84 → 138 BPM），剪辑密度跟着它从 1.4 秒一刀加到 0.22 秒一刀，最后在一个强拍上停在红带蝶上。

画面全部由 JavaScript 在 canvas 上画出来，没有贴任何原视频的像素；音乐是为这条剪辑表专门写、用 numpy 逐个音符合成的原创曲。

## 设计

- **一个主体，两种处理。** 每张图先画平面的背景和标本，再用同一种工艺（`js/crafts.js`）分别处理背景和主体：主体更细密、方向从翅根向外放射（像翅脉），背景更粗、换方向。没有描边，主体的边缘只是处理方式变化的地方。
- **背景来自这只蝴蝶自己的翅膀**（`js/grounds.js`）：黄窗斑蛾背景是它的三条黄窗斑和腹部色环，斑蛾是黑圈红点，绿带凤蝶是一排绿方块，灰蝶是鳞片纹，达摩凤蝶是奶黄逗点和格子，夹竹桃天蛾是波浪带，红带蛱蝶是斜红条和折线，透翅蛾是翅脉格子和放射线……明度和主体相反：深色标本配浅底，浅色标本配深底，每张都测过主体/背景亮度差（71–173，Kevin 的是 78–116）。
- **反相版。** 深色物种太多，有 7 张用了反相印刷（深色翅变成纸色，浅色斑变成墨色，鲜艳的点缀色保留；背景同色相反明度），这样明暗能一直交替，连续同明度最多三张。
- **十种工艺**：丝网（错版+干刷痕）、麻胶版（刻刀痕）、马赛克、十字绣、半调网点（riso）、铜版线刻、水粉点、缎面绣、翅鳞、点描。每个物种三次出场用三种不同工艺和三套不同背景，相邻两张从不重复工艺。
- **静止。** 每张图只画一次并缓存，同一张图内的帧完全相同（检测：图内像素变化 0.00%），所有变化都在切点上。

## 音乐

`tools/music.py` 写出并合成整首曲子：马林巴、拨弦低音（Karplus-Strong）、木鱼、沙锤、轻底鼓、钟琴，D 小调，最后落在 Dm(add9)。

速度是连续的指数加速，84 → 138 BPM（真正的 BPM 变化，不是变响或者加乐器），剪辑在音符上：

| 小节 | 切点 | 每张时长 | 音乐 |
| --- | --- | --- | --- |
| 1–2 | 每 4 个八分音符 | 1.41–1.31 s | 四分音符琶音，低音和木鱼落在切点 |
| 3–5 | 3+3+2 八分音符 | 0.97 / 0.62 s | 八分音符固定音型，重音按 3+3+2，低音、木鱼在重音上 |
| 6–8 | 每拍 | 0.56–0.48 s | 十六分音符音型，底鼓和木鱼每拍 |
| 9–10 | 每个八分音符 | 0.24–0.22 s | 钟琴每个八分音符一个音，上行到终止 |
| 11 | 终止和弦 | 1.75 s | 停在红带蛱蝶上，和弦自然衰减 |

每个切点都有一个重音落在上面。切点取最近的整帧（30 fps），离音符最多 1/60 秒；成片里实测切点到音符起音的偏差平均 +1 ms（`tools/sync_check.py`）。

**关于现成音乐：** 先找过可合法使用、节拍真加速的现成曲目。Pixabay Music 在这个环境里返回 403，Freesound 的 CC0 搜索也没有合适的器乐。所以写了原创曲，没有第三方授权问题，切点也能精确地踩在音符上。

## 重新生成

```bash
python3 tools/music.py
node ../.claude/skills/line-drawn-music-film/scripts/render.cjs --project . --audio audio/music.mp3 --fps 30 --out out/butterfly.mp4
python3 tools/sync_check.py out/butterfly.mp4
node tools/check.cjs            # 所有图拼成一面墙，并逐张检查对比度
```

`tools/music.py` 写出 `audio/music.mp3` 和 `js/beats.js`（切点）。在浏览器里打开 `index.html` 可以直接带声音播放（空格暂停，方向键跳转）。

成片：1080×1080，30 fps，H.264 High / yuv420p，AAC 44.1 kHz，24.27 秒，42 张图，约 19 MB。
